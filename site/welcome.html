Download and install

Run the installer and click through it. It does not need administrator rights. Windows may warn you about an unknown publisher: choose More info, then Run anyway.

Download FIRE for Windows

Enter your licence key

Open FIRE, click Account at the top right, paste the key above and choose Apply licence. That is the whole of activation. There is no account to create and no password to remember.

Look around in demo mode first

FIRE opens in demo with a simulated balance. Place a few orders and watch a window settle. Nothing here touches an exchange and no money is involved, so it is a free place to get the feel of it.

Connect your exchange account

Create an API key in your exchange account, then paste the key ID and the private key file into FIRE's setup screen. FIRE encrypts it with Windows' own secret store and it never leaves your computer.

Use a key created specifically for FIRE rather than one you already use elsewhere. If you ever need to revoke it you then cut off one thing rather than everything at once.

Before your first live order. Check the banner across the top of the window. Blue and PAPER means simulated. Red and LIVE means real money and orders that are final. Set your maximum loss per order in Preferences before you switch.
